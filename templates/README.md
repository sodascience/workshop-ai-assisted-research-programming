# Templates

These templates define the structure of two documents you will save and track locally with Git. They describe the research and planned work; they do not contain implementation code.

| File | Purpose |
|---|---|
| [study_design_template.md](study_design_template.md) | Records the research question, data, variables, methods, verification needs, and unresolved decisions. |
| [implementation_plan_template.md](implementation_plan_template.md) | Turns the approved design into small numbered tasks, each with inputs, deliverables, dependencies, and verification requirements. |

## How to use

1. In the first UU AI Chat conversation, attach the study-design template and use the corresponding [prompt](../prompts/README.md). Develop and review the design, then save it locally as `study_design.md` and commit it.
2. In a new conversation, attach that design and the implementation-plan template, then use the implementation-plan prompt. Review the plan, save it as `implementation_plan.md`, and commit it.

Keep provisional decisions clearly labelled. Later revisions should change only the affected sections, preserving unrelated text and formatting.

See the [worked example](../examples/README.md) for completed documents.
